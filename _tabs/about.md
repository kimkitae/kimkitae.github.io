**김기태의 AX 작업노트 · KFlowLabs**는 김기태가 직접 겪은 테스트 자동화와 AX(AI 전환) 작업을 기록하는 기술 블로그입니다. 글에는 작성자의 경험과 판단을 담고, AX·자동화 협업 문의는 KFlowLabs로 연결합니다. 어떤 문제를 만났고, 무엇을 시도했으며, 어디서 실패했는지를 설명합니다.

KFlowLabs는 김기태가 운영하는 AX·업무 자동화 협업 창구입니다. 블로그의 경력과 프로젝트는 확인 가능한 공개 이력을 기준으로 다룹니다.

운영자 **Kim Kitae(김기태)** 는 모바일 QA와 자동화를 중심으로 일해 왔습니다. Appium, Espresso, XCUITest를 이용한 모바일 자동화, Jenkins 기반 릴리스 검증, Slackbot과 내부 API를 이용한 테스트 도구, LLM/RAG를 활용한 스크립트 검색 실험을 진행했습니다. 자세한 경력은 아래에 짧게 정리합니다.

- 모바일 자동화의 구조와 유지보수 전략
- 테스트 데이터, 인증, 로그를 다루는 내부 도구 설계
- LLM/RAG를 자동화 업무에 적용할 때의 현실적인 한계
