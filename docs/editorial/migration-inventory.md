## Canonical and hreflang rules

- Korean posts use the existing `/posts/<slug>/` URL and a self canonical generated by `jekyll-seo-tag`.
- English pages use `/en/posts/<slug>/` and a self canonical. They are pages with `layout: post`, not entries in `site.posts`.
- Each Korean post has `translation_url: /en/posts/<slug>/`.
- Each English page has `translation_url: /posts/<slug>/`.
- `_includes/head.html` emits reciprocal `hreflang` links from `lang` and `translation_url`.
- English pages are not canonicalized to Korean.
