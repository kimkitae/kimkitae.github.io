# 결제 화면 반복 테스트, 소프트웨어 밖으로 나가 본 이야기

결제 수단이 여러 개인 서비스를 운영하면 배포마다 주문부터 결제 완료까지 모든 수단을 확인해야 합니다. 보안이 강한 결제 화면은 캡처가 비어 있거나 가상 키패드 배열이 매번 달라서, 일반적인 UI 자동화만으로는 반복 검증이 어렵습니다. 이 글은 그 반복을 줄이려고 하드웨어를 붙여 본 실험의 중간 기록입니다.

## 하드웨어를 고민한 이유

화면을 읽는 대신 사람의 손가락 동작을 물리적으로 흉내 내는 방법을 생각했습니다. 카메라로 화면을 보고, 라즈베리파이가 좌표를 계산하고, 아두이노가 서보를 움직여 XY 플로터가 필요한 지점을 누르는 구성입니다. Appium은 앱 상태를 준비하고 클릭 결과를 다시 확인하는 역할을 맡는 설계였습니다.

## 어디까지 했나

원문에 따르면 하드웨어는 조립했지만 소프트웨어 구현은 마무리하지 못했습니다. 그래서 이 구조가 실제 단말에서 끝까지 동작했다고 볼 수는 없습니다. 원문에는 단말 크기별 플로터를 만들어 1개 단말에 1개 플로터를 연결하고, 24/7로 BDD 시나리오를 돌리고 싶다는 목표가 남아 있습니다.
